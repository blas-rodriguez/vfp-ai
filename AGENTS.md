# Project instructions

- This is a standalone public-project scaffold; do not import files from sibling projects.
- Target generated applications and examples at Microsoft Visual FoxPro 9.0.
- Keep demo behavior explicitly labeled; do not present fixed responses as AI output.
- Keep VFP PRG source ASCII until a tested code-page policy is established.
- Never commit credentials, user conversations, real business DBF data, or proprietary binaries.
- Keep API adapters separate from VFP artifact generation.
- Run available VFP compile and object-instantiation checks when changing PRG code.
- Document unavailable validation honestly; do not claim full GUI testing from compilation alone.
- Do not execute model-generated code on production data.
