# Contribuir

El proyecto está en una etapa inicial y se distribuye bajo la licencia MIT.
Los aportes deben poder distribuirse bajo esa licencia. Antes de incorporar
código de terceros, verificar su licencia y conservar los avisos correspondientes.

1. Describir el problema o el ejemplo de VFP que se quiere incorporar.
2. Trabajar en una rama independiente y limitar el cambio a ese objetivo.
3. Mantener el código generado y los ejemplos compatibles con VFP 9.0.
4. Documentar cómo se probó y qué dependencias requiere.
5. Adjuntar únicamente datos sintéticos y archivos que se puedan redistribuir.

Los PRG iniciales usan ASCII para evitar problemas con las páginas de códigos
de VFP. La documentación usa UTF-8. Una política de codificación con soporte de
acentos en la interfaz deberá definirse antes de incorporar textos localizados.

No incluir claves API, DBF reales, conversaciones privadas, ejecutables de VFP
ni bibliotecas comerciales. No introducir solicitudes de red ni ejecución de
código generado en el modo demo.
